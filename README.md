# parsiannight.github.io

Personal site of Omar Abdelrazik. Plain HTML and one stylesheet, no build step.

- `index.html` — home page (edit experience and highlights here)
- `blog/posts.json` — post list; add a post by adding an entry and a `blog/posts/<slug>.md` file
- `css/site.css` — all styling; light/dark follows the visitor's OS setting

Open `index.html` locally through any static server, e.g. `python3 -m http.server`.
